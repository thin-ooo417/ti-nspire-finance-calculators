TI-NSPIRE BUSINESS FINANCE CALCULATORS
How to put them on your calculator
======================================================================

This download holds 44 calculator sheets:

  finance/     44 sheets, 01 to 44
  README.txt   this file

They have been tested on a computer but not yet on a calculator.
Check one sheet (step 6) before relying on the rest.


YOU NEED
----------------------------------------------------------------------

- A TI-Nspire CX or CX CAS calculator and its USB cable.
- TI-Nspire Computer Link Software on a Windows or Mac computer. It
  is free from education.ti.com: search the site for "Computer Link".
- This download unzipped, for example to your Desktop.


STEPS
----------------------------------------------------------------------

1. Turn the calculator on and plug it into the computer.

2. Open TI-Nspire Computer Link Software.

3. In the Select Handheld window, click your calculator, then
   Select. Not listed? Push the cable in fully and click Refresh.

4. You now see two panes:
     top pane      your computer   (Computer File Browser)
     bottom pane   the calculator  (TI-Nspire File Browser)

5. In the top pane, go to where you unzipped this download. Drag
   the folder "finance" into the bottom pane.

   Drag only that folder, not this README.txt. Computer Link only
   copies calculator files and cancels the whole copy if you include
   anything else.

6. Check it worked. On the calculator press [home], open My
   Documents, then finance, then the sheet below. Press the keys
   shown and compare the result. Words in square brackets are keys
   to press; the rest are numbers to type.

  03_Present_Value
      press:   5000  [enter]  0.07  [enter]  1
      shows:   PV  4672.9

One more, for a sheet with a different layout:

  10_Bond_Price
      press:   4  [enter]  100  [enter]  3  [enter]  0.05
      shows:   PB  price  97.2768

If the results match, you are done.


USING A SHEET
----------------------------------------------------------------------

- [up] and [down] (or [enter], or [tab]) move between fields.
- Type with the number keys, the decimal point and the (-) key.
- Type rates as decimals: 0.08 for 8%.
- [backspace] deletes a character. [esc] empties the field.
- A grey value is a default, used while the field is empty.
- Orange text is a warning about your inputs. A red entry is not
  a complete number yet, and no results show until it is fixed.

If the calculator asks to save changes when you close a sheet,
either answer is fine.


IF SOMETHING GOES WRONG
----------------------------------------------------------------------

The calculator is not in the Select Handheld list
    Turn it on, push the cable in fully at both ends and click
    Refresh. Then try another USB port.

Computer Link says a file is not supported and copies nothing
    You included README.txt. Drag only the "finance" folder.

A sheet will not open
    Copy that file again in case the copy was cut short. If it still
    fails, report it with the sheet name.

The result does not match the check
    Make sure you pressed the keys exactly as shown. If it still does
    not match, report it with the sheet name and what you saw.

Nothing appears under the fields
    The sheet needs more inputs.


NEWER VERSIONS
----------------------------------------------------------------------

Copy the new folder in the same way. When Computer Link asks whether
to replace a file with the same name, answer yes.


CX II CALCULATORS
----------------------------------------------------------------------

Computer Link does not work with CX II models. TI's help says they
need version 5.0 or later of the TI-Nspire computer software, such
as the Student Software. These sheets have not been tried on a CX II.
